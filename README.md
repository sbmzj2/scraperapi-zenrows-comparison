## ScraperAPI 到底是什么？三句话讲清楚

ScraperAPI 是一个 Web Scraping API服务。你把目标 URL 丢给它，它帮你处理代轮换、CAPTCHA 绕过、浏览器指纹、请求头管理这些脏活累活，返回干净的 HTML 或 JSON。

它成立于 2018 年，服务器节点覆盖全球超过 50 个地理位置，代理池包含超过 4000 万个 IP 地址。支持住宅代理和数据中心代理两种模式。对于需要渲染 JavaScript 的页面（比如 SPA 架构的电商站），它内置了无头浏览器渲染能力，不需要你自己搭 Puppeteer 集群。

简单说：你写采集逻辑，它负责让请求不被封。

## 什么情况下我不推荐 ScraperAPI

说几个不适合的场景，免得你花了钱发现不对：

- **纯 API 数据接口采集**：如果你抓的是 JSON API 而不是网页，根本不需要反封锁服务，直接用普通代理池就够了。
- **需要长会话保持的场景**：比如模拟登录后连续操作多个页面，ScraperAPI 的无状态请求模式不太适合。
- **预算极度紧张且量极小**：每月只需要几千次请求的话，免费套餐够用，但没必要付费。

## 常见问题

### ScraperAPI 支持哪些编程语言？

它本质上是一个 REST API，任何能发 HTTP 请求的语言都能用。官方提供了 Python、Node.js、Ruby、PHP 的 SDK，Java 和 Go 社区也有封装好的库。我自己用 Python 的 requests 库直接调，三行代码就能跑起来。

### JS 渲染和普通请求的 credits 消耗差多少？

普通请求 1 credit，开启 JS 渲染（render=true）消耗 10 credits，使用住宅代理额外消耗 10 credits。如果同时开启 JS 渲染 + 住宅代理，单次请求消耗 25 credits。这个倍率在选套餐时一定要算清楚。

### 可以中途升级或降级套餐吗？

可以。升级即时生效，差价按比例补缴。降级在当前计费周期结束后生效。不存在锁定期。

### 退款政策是怎样的？

ScraperAPI 提供 7 天无理由退款。我当时特意确认过，年付套餐也适用这个政策。不过建议先用免费套餐跑通再决定付费，省得折腾退款流程。

### 跟自建代理池比，成本到底是高还是低？

取决于你的规模。如果月请求量在 500 万以下，算上服务器成本、代理 IP 采购、运维人力、反封锁策略维护的时间成本，用 ScraperAPI 大概率更划算。超过这个量级，可以考虑混合方案或者直接谈 Enterprise 定制价。

### ScraperAPI 能绕过 Cloudflare 吗？

能处理大部分 Cloudflare 防护，包括 JS Challenge和 Turnstile。但对于开启了严格 Bot Management 的企业级 Cloudflare 配置，成功率会下降。这种情况建议开启住宅代理 + JS 渲染组合，成功率能拉回来不少。
